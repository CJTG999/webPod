Quick note: webPod is local-first.

Your music library is stored in this browser's IndexedDB. Your audio files are not uploaded to a webPod server. Keep a ZIP backup if you plan to clear browser data or move to another device.

01 / Start here

Getting started

webPod is a browser-based music player with a retro click-wheel interface, synced lyrics, audio controls, and companion tools. You do not need an account.

  1. Open the webPod player in the browser you want to use as your music library.
  2. Choose the option to add or upload music and select audio files from your device.
  3. Select a track in your library and press play. Your imported tracks are saved in browser storage.
  4. Optionally add lyrics, adjust the sound, and create a ZIP backup from the Backup Manager.
For the player and companion tools to share the same library, open them from the same site origin and browser profile. A different browser or a different hostname has separate storage.
02 / Your music

Add music to webPod

Import audio files you already have access to. webPod reads supported audio in your browser and stores the library locally.

Basic workflow

  1. Open the player and find its music import / add-track control.
  2. Select one or more audio files from your device.
  3. Let the import finish, then choose a track from your library.
  4. If the title or artist is missing, edit the track details if the player offers that option, or use a clearly named file as a fallback.

Common formats include MP3, WAV, OGG, FLAC, M4A, AAC, and other browser-supported audio formats. Actual playback support can vary by browser and codec.

Only import music you have the right to use. webPod is a player and library tool, not a music download service.
03 / Where things live

Your library & browser storage

The player and Backup Manager use the browser database webPodMemoryDB (IndexedDB), including the tracks store. This is why the tools can work with the same songs without uploading them to a web server.

Stored on this browser

Tracks and their saved metadata remain available in the same browser profile.

Not cloud sync

Browser storage does not automatically follow you to another device, browser, or profile.

Private browsing sessions, clearing site data, browser storage limits, or browser resets can remove local data. Export a backup before making major browser changes.

04 / Lyrics

Add synced lyrics

Lyrics can be fetched from LRCLIB when a match is available, or supplied from your own SRT/LRC file. The player uses timestamps to show the right line as the song plays.

  1. Choose a track in webPod.
  2. Use the lyrics area to search for lyrics or load your own file.
  3. Check that the title, artist, and timing match the audio.
  4. Play the track and watch the active line update.

Fix lyrics that are early or late

Use the per-track lyric offset to move the displayed lyrics earlier or later. If the timing gradually drifts across the song, adjust the caption rate rather than relying only on a fixed offset. The offset and rate controls are saved per track.

A positive or negative offset shifts the timing as a whole. Rate adjustment changes how quickly the timestamps progress. Make small changes, replay a few checkpoints, and compare the beginning and end.
05 / File examples

SRT & LRC file examples

Both formats describe text paired with timestamps. Save the content as a plain-text file with the matching extension.

[ti:Example Song]
[00:12.00]First lyric line
[00:16.50]Second lyric line
[00:20.00]Third lyric line

Example .SRT

3

FormatTimestamp styleGood for

These are small examples to show the format, not a complete song. Keep timestamps in chronological order and use a blank line between SRT entries.

06 / Create captions

Caption Studio: make captions while listening

Use Caption Studio when you want to build a caption file from scratch instead of importing an existing one.

  1. Open Caption Studio from the site.
  2. Load the audio you want to work with and prepare your caption text.
  3. Play the audio and use the timing controls / hotkeys to mark caption starts and ends.
  4. Review the timeline and preview, correct any timing mistakes, then export your captions.

The tool includes a multi-track audio workflow and a live preview. It is useful for lyric videos, karaoke-style projects, and timing captions to a song or audio mix.

Tip: work in short sections. Mark a few lines, replay that section, and fix the timing before moving farther into the track.
07 / Retiming

SyncMaster: fix an existing lyric file

Use SyncMaster when you already have the words but need to create or repair their timestamps.

  1. Open SyncMaster and load an audio file.
  2. Import or paste the lyric lines.
  3. Choose Continuous mode to set a line's start and automatically finish the previous line, or Tap Range to mark both the start and end.
  4. Play the song and stamp each line as it is heard. Use the waveform / progress area to move around.
  5. Review the result and export as SRT or LRC.

Continuous mode is convenient for ordinary lyric timing. Tap Range gives you direct control over each line's duration.

08 / Playback

Playback controls

The player has a retro click wheel and keyboard controls. The exact on-screen controls are also available to click or tap.

KeyAction
↑Open the menu / navigate to the library
↓Play or pause
←Previous track or restart current track

Playback also supports shuffle and repeat modes. If a keyboard shortcut does not work, click the player first and make sure a text field or browser control is not capturing the key.

09 / Sound

Equalizer, bass boost & playback speed

The built-in five-band equalizer uses Web Audio processing. Start with a preset, then make small changes to suit your headphones or speakers.

PresetTry it for
FlatA neutral starting point
Bass HeavyMusic where you want more low-end emphasis
Vocal BoosterMaking vocals stand out in a busy mix
Treble BoostAdding emphasis to higher frequencies
RockA shaped, energetic general-purpose sound

Bass Boost adds extra low-frequency emphasis. Playback speed can be adjusted from 0.5× to 2×, which can help when studying a tricky musical passage or checking lyric timing.

If the audio sounds distorted, return the EQ to Flat and turn off Bass Boost before adjusting one band at a time.
10 / Visuals

Visualizer tips

The LCD visualizer draws a live representation of the audio. Available styles include spectrum bars, waveform, oscilloscope, VU meter, and other display modes.

  • Try a different style if the current one is hard to read.
  • Lower sensitivity or smoothing if the display feels too jumpy.
  • Use a lower frame rate or disable the visualizer on slower devices to prioritize playback performance.
11 / Backups

Back up and restore your library

The Backup Manager exports your library as a ZIP file. It includes a manifest and audio files, along with track metadata and saved lyric information.

Export a backup

  1. Open Backup Manager from the same webPod site and browser profile.
  2. Check that your tracks appear in the library list.
  3. Choose the ZIP export option and save the downloaded file somewhere safe.

Restore a backup

  1. Open Backup Manager in the destination browser / profile.
  2. Choose the ZIP file you previously exported.
  3. Wait for the import to finish, then refresh the player library.
Importing a backup merges tracks by ID; an existing track with the same ID may be replaced. Keep an untouched copy of your ZIP before importing if you are unsure.
12 / On the go

Use webPod on mobile

webPod has a mobile-friendly layout and can be installed as a Progressive Web App when the browser offers an install or Add to Home Screen option.

  1. Open your webPod site in a supported mobile browser.
  2. Open the browser's share or menu controls.
  3. Choose Add to Home Screen / Install if available.
  4. Launch webPod from the new home-screen icon.

Mobile browser storage is still local to that browser. Use Backup Manager to move your library between devices.

13 / Put it together

Use cases & example workflows

Build a personal music library

Import your audio, tidy up track details, choose a theme, and keep a ZIP backup somewhere safe.

Karaoke / sing-along

Find or import synced lyrics, correct the offset, then use the LCD lyric display while the song plays.

Make timed captions

Use Caption Studio to create new captions, or SyncMaster to timestamp lyrics you already wrote.

Move to a new computer

Export a ZIP on the old device, open the same webPod deployment on the new one, and import it.

Example: from a new song to synced lyrics

  1. Import the audio file into the player.
  2. Search LRCLIB or load an LRC/SRT file.
  3. Listen to the first verse and adjust the offset if the lines are consistently early or late.
  4. Check a later section; if the drift changes over time, adjust the lyric rate.
  5. Export a ZIP backup once the track is set up.
14 / Help

Troubleshooting

My songs disappeared. What happened?

Check that you are using the same browser, browser profile, and site address as before. Clearing site data or using private browsing can remove or isolate IndexedDB data. Restore a ZIP backup if you have one.

Why can't the Backup Manager see my tracks?

Open it from the same webPod deployment and browser profile as the player. Different origins (including different hostnames) do not share IndexedDB.

My audio file will not play.

Try another browser-supported format, confirm the file plays locally in another player, and check that the browser supports its codec. Some containers or codecs are not supported by every browser.

The lyrics are out of sync.

Use the per-track offset for a consistent early/late shift. If the timing gradually drifts, adjust caption rate. For major problems, retime the file in SyncMaster.

LRCLIB did not find my song.

Check the track title and artist spelling. If there is no match, import an LRC/SRT file or create timestamps in SyncMaster.

Playback stutters or the interface feels slow.

Try disabling the visualizer or lowering its frame rate and effects. Close other heavy tabs and test again.

Can I share my library through a link?

The library is stored locally in your browser; it is not a hosted public playlist. Use a ZIP export to transfer your own library between devices.

15 / Quick answers

Frequently asked questions

Do I need an account?

No. The browser version does not require an account.

Are my songs uploaded?

The local library and audio storage are handled in your browser. Lyrics lookup uses LRCLIB when you request it; your local audio library is not a cloud music locker.

Will my library sync automatically?

No. Use Backup Manager to export and import a ZIP between browsers or devices.

Can I use my own lyrics?

Yes. The player supports SRT and LRC files, and SyncMaster can help create timestamps.

Where do I report a bug?

Visit the webPod GitHub issues page and include your browser, device, and steps to reproduce the problem. Do not attach private audio files unless you intend to share them.
